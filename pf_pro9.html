WMS Almacenes

SQLSAP ExcelPythonAppsheet
Duración: 2 Meses
Estado: Concluido
Rol: Supervisor de almacén

Objetivos

  • Optimizar la gestión de inventarios
  • Implementar códigos de barras
  • Asignar zonas en todo el almacén
  • Controlar los movimientos y ubicación
  • Registrar movimientos de productos

Desarrollo

El proyecto comenzó con un levantamiento detallado de ubicaciones de racks, información de productos y movimientos de mercancías en SAP. Se implementaron códigos de barras para identificar ubicaciones en racks y productos. Se asignaron zonas en todo el almacén para una organización más eficiente.

El proyecto fue dividido en etapas: Levantamiento de ubicaciones → información de producto → movimientos SAP → impresión códigos barra → rotulado de pallets → asignar zonas → registrar movimientos.

Herramientas

  • SAP: Para el registro de movimientos de mercancías
  • Appsheet: Implementación de códigos de barras y control de movimientos
  • Excel + Macros VBA: Tecnología de códigos de barras para la identificación
  • Python: Análisis complementario y limpieza avanzada

Conclusiones

La implementación del WMS en almacenes mejoró significativamente la eficiencia y precisión en la gestión de inventarios y movimientos. La asignación de zonas y el uso de códigos de barras optimizaron la organización del almacén.
