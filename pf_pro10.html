Descripción

Desarrollo de un aplicativo móvil integral con AppSheet conectado a SQL Server para gestionar todas las operaciones logísticas de la empresa: despachos, inventarios, revisiones, reportes y control en tiempo real desde múltiples sucursales.

Módulos del Aplicativo

  • Revisión de Despachos: Conteo a ciegas por choferes y validación automática
  • Control de Inventario: Toma de inventarios y registro de diferencias
  • Registro de Personal: Gestión de accesos, roles y permisos por sucursal
  • Seguimiento de Rutas: Estado de despachos (pendiente / en revisión / terminado)
  • Reportes Automáticos: Generación de reportes diarios y exportación a Excel
  • Dashboard en PowerBI: KPIs conectados a los datos del aplicativo en tiempo real

Arquitectura Técnica

  • AppSheet: Frontend móvil y web, lógica de negocio y flujos de trabajo
  • SQL Server: Base de datos central con tablas de despachos, productos y personal
  • Python: Scripts de procesamiento, limpieza y análisis de datos
  • SAP: Integración con el sistema ERP para datos de inventario y SAP
  • Power BI: Capa de visualización conectada directamente a SQL Server
